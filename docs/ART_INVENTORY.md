# Art inventory

Generated by `tools/art_inventory.gd` from `assets/packs/` and `data/assets/manifest.json`. Contact sheets are in `tools/inventory/<pack>.png` (and `_2`, `_3`... for big packs). Regenerate after adding packs or manifest entries.

## Style guide (which pack goes where)

| Area | Packs |
| --- | --- |
| Downtown | Tiny City (roads, cars, storefronts) mixed with Ninja Adventure floors and props |
| Residential | Tiny Town plus Ninja Adventure TilesetHouse and TilesetNature; roofs come in tinted variants (data/town/styles.json roofTints) |
| Outskirts | Ninja Adventure TilesetNature, Field, Relief and Water; Tiny Factory for the factory |
| Interiors | Ninja Adventure Interior |
| Upside-Down | Tiny Dungeon plus DungeonTileset II plus recolored town tiles (M20) |
| Combat props and markers | Tiny Battle |
| Extra creatures | Tiny Creatures for Upside-Down enemies |
| UI | UI Pack Pixel Adventure (via the M11 skin) |
| Input prompts | Input Prompts Pixel |

Keep one look per zone: mixing packs is fine inside a zone as long as the zone stays consistent.
