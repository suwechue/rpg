# Your art goes here

Drop a file named after an asset id and it replaces the pack version. No code or manifest changes.

- `assets/custom/portraits/portrait_kelly.png` (or just `assets/custom/portrait_kelly.png`)
- `assets/custom/tiles/tile_road_h_top.png` replaces one tile everywhere it's used
- `assets/custom/music/music_town.ogg`

Every id, its size and frame layout is listed in `docs/ASSETS.md`. In the game, press F1 > Art and choose **Reload custom art** to see changes without restarting.
